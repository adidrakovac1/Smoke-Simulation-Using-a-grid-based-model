# reference

Ovdje se čuvaju **referentni rezultati serijske verzije** (po računaru, npr. `serial_64_100steps_pc2.bin` i sažetak `.bin.txt`:
kontrolni zbir, min, max, srednja vrijednost). Sve kasnije verzije (vektorizovane, OpenMP, GPU) se
porede s njima. Postupak: `../../docs/plan/VERIFICATION.md`, odjeljak 3.

Fajlovi se dodaju tek kad je serijska verzija ispravna i provjerena (milestone M3).
